The angle does not move / sensor trouble

Angle Dare needs a device with a rotation-vector motion sensor. Turn the phone slowly and hold it upright; very old or heavily modified devices may not report the sensor. Close and reopen the app, then try Retry on the sensor screen. The simulator cannot play the real sensor loop.

The target disappears too quickly

The target is intentionally shown briefly so the live angle stays hidden. You can replay a round or use a challenge code to practise the same target again.

My score or Gold did not update

Finish the result screen and return Home. Core progress is local and offline; if the app was killed mid-transition, replay the round. Android cloud save is optional and requires Play Games sign-in.

Purchases and restore

  • Restore Purchases is on the Premium screen and in Settings.
  • Monthly Premium renews through Apple/Google; cancel/manage it in the store account settings.
  • Lifetime is a one-time purchase and never renews.
  • If a purchase is pending or fails, wait for the store, then tap Restore Purchases. Contact the store for refunds.

Ads

Free play uses Unity LevelPlay with Unity Ads and Liftoff. Premium removes ads. If an ad is blank or fails to load, wait for the next natural break; the game never blocks a round on an ad. Report a bad ad from Settings → Report an Ad.

Sharing

Result cards are generated locally. The share sheet is provided by iOS/Android; if the target app does not accept images, update it or choose another destination.

Privacy choices

The current release does not request ATT and uses fail-closed consent for personalized ads. Use Settings → Privacy Choices to review the controls available in the app.

Data deletion

Clear the app's data or uninstall it to remove local progress. Store purchases remain restorable with the same store account.

Contact

Send the app version, iOS/Android version, device model, and a short description to contact@baripas.studio. Do not send payment-card details.
